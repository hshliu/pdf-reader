PDF.js / Adobe Acrobat / Apple Books 都采用四容器分层架构。我们的当前结构是扁平的。

关键差异对比

维度 当前 四容器架构
侧边栏 浮动面板，移入移出 固定容器，始终可见（可收起）
缩略图 无 SFT 网格布局，双向同步
阅读模式 单页翻页 连续滚动 + 页面分隔条
文档主题 与 chrome 绑定 独立于 chrome 主题
渲染策略 全量加载单页 视口渲染 + DOM 虚拟化
A

采用四容器架构

按 PDF.js 标准重构布局：固定侧边栏 + SFT 缩略图 + 连续滚动 viewer。这是行业标准。

B

保留当前，局部改进

保持浮动侧边栏 + 单页模式，仅增加缩略图和文档主题分离。改动小但不够专业。
