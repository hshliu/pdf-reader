第五步：组件架构 — 单体 vs 可组合

react-pdf 提供 Document/Page/Outline/Thumbnail 四个可组合原语。EmbedPDF 使用插件架构。当前代码是单体 loadPage() 函数（450行 app.js）。

当前：单体 app.js
app.js — 单体模块 (~450行)
1 个全局 state 对象，所有函数直接读写
loadPage() → fetch + 渲染DOM + 标记进度 + 存书签 + 更新面包屑 + 更新按钮 + scrollTo
selectPdf() → fetch info + fetch toc + 显示reader + updateBreadcrumb + renderSidebar + loadPage
renderSidebar() → renderFileTree + renderToc + renderProgressList
函数职责过多、难以独立测试、无法局部替换
目标：五模块可组合
DocumentLoader · loader.js
fetch info/toc/pages · 缓存 · 预请求队列
↕ data
PageRenderer · renderer.js
HTML → DOM · 虚拟化回收 · 页面分隔条
↕ events
ScrollController · scroller.js
IntersectionObserver · 消抖 · 同步缩略图
ThumbnailPanel · thumbnails.js
SFT 网格 · 当前页高亮 · 点击跳转
ThemeManager · theme.js
Chrome ↔ Doc 双层主题 · CSS filter · 0.2s 过渡
单一职责 · 独立可测 · 可替换
